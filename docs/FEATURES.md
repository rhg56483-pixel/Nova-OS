# قائمة الميزات والحالة

«منفذ» يعني ملفات/حزم وإعدادات فعلية في المشروع، وليس إثبات نجاحها في صورة مقلعة.

| الميزة | حالة التنفيذ | دليل الاختبار المتاح |
|---|---|---|
| GitHub Actions يدوي | منفذ بالمسار الصحيح | YAML وبنية فُحصا؛ تشغيل GitHub لم يحدث |
| Debian 13 + live-build | منفذ | خيارات تُفحص بإصدار live-build من trixie؛ بناء كامل لم يحدث |
| LXQt/Openbox/SDDM/Plymouth | منفذ | حزم متاحة، configs ساكنة؛ جلسة رسومية لم تختبر |
| هوية/لوحة/خلفيات HD و4K | منفذ SVG وثيمات Linux | SVG/XML صالح؛ الشكل النهائي في جلسة يحتاج مراجعة |
| العربية/RTL/إنجليزية/Alt+Shift | منفذ | حزم وترجمات ومفاتيح locale؛ اتصال الحروف والتاريخ يحتاج اختبارًا بصريًا |
| Firefox/ملفات/طرفية/إعدادات/مهام/وسائط/ضغط | حزم وإعدادات فعلية | أسماء واعتماديات APT فُحصت؛ الاستخدام يحتاج Live |
| تحديثات النظام/Synaptic | منفذ | يبقي مصادر Debian الأمنية؛ تنفيذ الترقية يحتاج اختبارًا |
| Chromium/Flatpak/Brave/AppImage | تثبيت اختياري وأدوات/تعليمات | لم تُجر عمليات التثبيت في النظام الهدف |
| شبكة/صوت/Bluetooth/USB/إشعارات | مكونات فعلية | اختبار عتاد/VM مطلوب |
| Calamares/حساب المستخدم/إزالة Live | تسلسل Debian مع تعديلات | إعدادات وترتيب الـjobs فُحصا؛ تثبيت فعلي مطلوب |
| BIOS/UEFI/حفظ ملفات بعد التثبيت | مدعوم في مسار البناء/المثبت | لا ISO ولا إقلاع ولا إعادة تشغيل متاحة؛ غير مثبت عمليًا |
| تكامل VirtualBox الأساسي | نواة/Xorg | لم يختبر؛ الحافظة/المشاركة تحتاج Oracle Guest Additions |
| هدف 2 GiB | قرار تصميم واختبار مجهز | غير مقاس؛ 4 GiB للتجربة الأفضل هدف لا نتيجة |
| تدوير زوايا كل النوافذ/blur | غير مفعل | استُبعد compositor للخفة |
| Secure Boot/تشفير/تثبيت مزدوج | غير مؤهل | تجنبها في اختبار النسخة الأولى |

لا ISO جاهز أو نسبة نجاح أو قياس أداء يمكن استخلاصه من هذا التسليم وحده.
