# نتائج مراجعة الأصل والإصلاحات

فُحصت جميع الملفات النصية الـ42 في ZIP الأصلي، بما فيها المجلدات المخفية (90 مدخلًا إجمالًا يشمل المجلدات). النسخة الأصلية محفوظة خارج مسارات البناء في `legacy-nova/`.

| المشكلة / الملاحظة | الإجراء |
|---|---|
| Workflow موجود أصلاً ويحتوي workflow_dispatch | أبقينا مساره، طورنا التسجيل والفشل والتنزيل؛ شرح وضع محتويات المجلد في جذر المستودع والفرع الافتراضي بدل الادعاء بأن الملف غائب |
| الأصل KDE + Discover ومؤثرات وlocales-all وعدة تطبيقات | LXQt + Openbox، حزم محددة بلا task كامل؛ Firefox وحده افتراضيًا، Synaptic بدل Discover |
| virtualbox-guest-utils وvirtualbox-guest-x11 غير موجودتين في فهارس trixie | أزيل الاعتماد المكسور وlauncher إلى VBoxClient غير موجود؛ توثيق Guest Additions الاختيارية، أبقينا دعم النواة وXorg |
| عناوين novaos.example وهمية | إزالتها من الهوية والمثبت |
| العربية مثبتة لكن LANG=en_US الافتراضي | ar_SA + English fallback وQt/Firefox l10n وخطوط Noto، Alt+Shift؛ اختبار بصري مطلوب |
| locale-gen/systemctl وغيرهما تبتلع أخطاء بـ || true | الخطافات الآن تفشل برسالة واضحة عند فشل إعداد مطلوب |
| rm -rf لمساحة عمل تحددها متغيرات المستخدم | mktemp لمساحة جديدة يملكها السكربت واختبار mount قبل البناء |
| الاكتفاء باختيار أول ملف ISO بالـ ls/head | اشتراط ملف واحد غير فارغ وفحص الهيكل ومداخل الإقلاع وSHA256 |
| إعدادات Calamares مختصرة وتفتقد أجزاء تسلسل Debian | الاعتماد على calamares-settings-debian وتعديل YAML أثناء البناء؛ أبقينا jobs مصادر APT/initramfs/grubcfg وغيرها |
| kernel/img تحمل أسماء Arch | حذف override القديم؛ تلك المفاتيح تخص systemd-boot ولا تسبب بذاتها خطأ GRUB، الذي يستخدم grubInstall/grubCfg. اخترنا GRUB مع ثنائيات المنصتين |
| hook bootloader-config الخاص بـ Debian يحاول apt install grub-pc/grub-efi | تجاوز هذا الـjob فقط وإبقاء grubcfg/bootloader؛ كلا platform bin مثبت، وإعدادات GRUB مخصصة قبل إنشاء الحساب. يحتاج اختبار تثبيت حقيقي |
| تنظيف live قد يخفي فشل purge أو يترك حسابًا/امتيازات Live | packages job الرسمي + cleanup منفصل يفشل بوضوح، يزيل المستخدم قبل إنشاء الحساب ويزيل autologin/sudoers |
| تحميل ISO دون مسار بديل للحصة/الحجم | أجزاء 1900 MiB + hashes + أدوات إعادة تجميع Linux/Windows + Release مسودة اختياري |
| لا قياسات أداء | أداة تقيس MemAvailable وmpstat وsystemd-analyze؛ لا أرقام مختلقة |
| scripts VirtualBox لا تتحقق من وجود الصورة والأوامر | إضافة تحقق وصلاحيات وحالة أخطاء، مع دليل يدوي |

لم تُحذف وظائف مهمة بصمت: التكامل المتقدم مع VirtualBox يحتاج تثبيتًا إضافيًا لأن حزمه غير متاحة في stable؛ compositor وتدوير النوافذ الفعلي مستبعدان للخفة؛ واجهات KDE استبدلت بنظيرات أصلية. إعداد الحساب يعمل في معالج التثبيت؛ إعداداته لاحقًا عبر أدوات Debian. التشفير والتثبيت المزدوج خيارات غير مؤهلة بعد.
